| Manual | For | What's inside |

| [Block Reference](BLOCK-REFERENCE.md) | Anyone adding content | Every block: what it's for, its settings, tips and limits |
| [Administrator Guide](ADMIN-GUIDE.md) | Whoever installs and runs the site | Requirements, installation, web server, updates, accounts and roles, publishing, backups, forms and email, security, troubleshooting |
| [Developer Guide](DEVELOPER-GUIDE.md) | Developers working on CanvasCore | Architecture, local setup, data model, rendering and parity, adding a block, state and saving, UI and API conventions, tests, releases |
